Panduan pemutar

Tampilan slide berasal dari berkas PPTX. Pemutar ini menggunakan HTML5 dan dapat dipasang pada situs web statis tanpa PowerPoint.

Panel Interaktif Digital (PID): aktifkan Mode PID (atau buka dengan ?pid=1), geser satu jari ke kiri untuk slide berikutnya dan ke kanan untuk slide sebelumnya. Dua jari dapat digunakan untuk memperbesar atau memperkecil slide. Saat diperbesar, tarik dengan satu jari untuk menggeser posisi. Pilih pena atau laser pada dok untuk mencoret atau menunjuk; dalam kedua mode tersebut, geser tidak berpindah slide. Gunakan tombol panah besar dan dok saat layar penuh.

Mode Presentasi Kelas: tekan tombol “Presentasi Kelas” atau buka ?kelas=1. Slide memenuhi bidang layar dan panel samping disembunyikan. Bilah alat tersembunyi otomatis; tekan tombol “Alat” untuk menampilkannya. Gunakan tombol “Simulasi” untuk membuka laboratorium, kemudian “Kembali ke slide” untuk melanjutkan presentasi. Tekan C untuk masuk/keluar dari mode kelas atau Esc untuk keluar.
